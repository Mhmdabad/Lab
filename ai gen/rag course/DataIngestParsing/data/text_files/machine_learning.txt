========================================================================
                 INTRODUCTION TO MACHINE LEARNING (ML)
========================================================================

1. WHAT IS MACHINE LEARNING?
Machine Learning is a subset of Artificial Intelligence (AI) that provides
systems the ability to automatically learn and improve from experience 
without being explicitly programmed. 

Instead of writing manual rules, you feed data into an algorithm, and the 
algorithm builds a model to make predictions or decisions.

2. HOW IT WORKS (THE CORE PIPELINE)
Data Collection -> Data Cleaning -> Choosing a Model -> Training -> Testing -> Prediction

3. THE THREE MAIN TYPES OF MACHINE LEARNING

A. Supervised Learning
The model learns from labeled training data (data that already includes the
correct answers).
- Example: Predicting house prices based on size, or classifying emails 
  as "Spam" or "Not Spam".

B. Unsupervised Learning
The model finds hidden patterns or intrinsic structures in input data 
that has no labels.
- Example: Customer segmentation (grouping customers by buying habits)
  or anomaly detection.

C. Reinforcement Learning
An agent learns by interacting with an environment. It receives rewards 
for good behavior and penalties for bad behavior.
- Example: Training a robot to walk, or teaching an AI to play chess/Go.

4. POPULAR PYTHON LIBRARIES FOR ML
If you want to start coding Machine Learning in Python, these are the 
must-know libraries:
- Scikit-learn: Excellent for traditional ML algorithms (Regression, Classification).
- Pandas & NumPy: Essential for data manipulation and math operations.
- TensorFlow / PyTorch: Used for Deep Learning and Neural Networks.

5. A SIMPLE EXAMPLE CONCEPT (Linear Regression)
Predicting a value (y) based on an input (x):
    y = mx + b
The machine learning algorithm's job is to look at your past data and 
figure out the best values for 'm' (slope) and 'b' (intercept) so it can 
accurately predict future 'y' values.
